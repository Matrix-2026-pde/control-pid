# 指标、有效性与独立验证

指标实现位于 `pid_metrics.m`、`response_time_metrics.m`、`disturbance_metrics.m` 和 `saturation_metrics.m`。位置/速度时间指标使用有限采样记录；时间指标可使用位置/速度 Hermite 插值，连续 `deval` 只作为对照，不替代原有有效性判据。

稳态估计、调节时间和峰值只有在记录窗口、误差带、样本密度和有效性条件满足时才报告；短记录或尾段不足时会保留 `NaN`/无效状态。常值扰动后的恢复时间从 `t=10 s` 起算，不等同于初始阶跃的调节时间。

历史采样算法与后来 Hermite 插值结果不能拼成一次实验。原始完整记录及公式保存在 [archive README](archive/README-original-2026-10-27.md)；当前入口和测试使用更新后的时间指标实现。

独立验证脚本检查解析自由响应、P 稳态公式、PID 稳态、容差收敛、极点/Routh 条件、模块化重构一致性、扰动前后力平衡和饱和 clamping 不变量。验证阈值是本项目检查条件，不是任意模型的误差保证。
