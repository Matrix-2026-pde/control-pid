# 模型、控制律与三阶段实验

## 对象与状态

质量–弹簧–阻尼对象为 `m*x'' + c*x' + k*x = u + d`。状态为 `x1=x`、`x2=x'`、`x3=integral(r-x1)`，控制律为 `u=Kp*(r-x1)+Ki*x3-Kd*x2`。默认参数是 `m=1`、`c=1`、`k=4`、`r=1`，求解器使用 `ode45`、`RelTol=1e-8`、`AbsTol=1e-10`。

## 阶段 1：增益对比

入口 `run_comparison.m` 比较 P、PD、PI、PID-5、PID-15、PID-30。`Ki=0` 时参考二阶降阶模型的自然频率、阻尼比和超调公式；`Ki>0` 时使用三阶特征多项式、极点、闭环零点和 Routh margin，不把单一二阶阻尼比套用到三阶结果。

本次图表入口实测观察：P/PD 的参考稳态误差约 `0.286 m`；PID-15 的调节时间约 `2.6265 s`、超调约 `24.193%`。这些数字仅对应当前参数与指标定义。

## 阶段 2：常值扰动

入口 `run_disturbance.m` 在 `t=10 s` 将外力从 `0` 切换到 `-4 N`，保持到 `30 s`。P/PD 的后稳态位置约 `0.42857 m`，PID-15 回到 `1 m` 附近。`verify_disturbance.m` 还检查扰动前轨迹、扰动符号、稳态力平衡、恢复定义和 Routh margin。

## 阶段 3：执行器饱和与 clamping

入口 `run_saturation.m` 固定 PID-15，比较：G1 理想执行器；G2 `u_max=5 N` 且积分不冻结；G3 `u_max=5 N` 且当饱和与误差同向时冻结积分。`u_max=5 N` 高于保持 `r=1 m` 所需的 `k*r=4 N`，但低于初始未限幅命令 `Kp*r=10 N`，因此能观察到饱和和 windup。

G3 的 clamping 改善本实验中的超调和调节时间权衡，但并非恢复理想执行器响应。非光滑切换点的 `u_des/u_act` 差异被保留为限制记录。
