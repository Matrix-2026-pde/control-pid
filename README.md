# 二阶机械系统的 PID 闭环仿真

本目录只使用基础 MATLAB（`ode45`、`odeset`、`roots`、`plot`），不依赖 Control System Toolbox，不使用 Simulink。所有文件均为新建；项目外的 HyperFrames 文件未改动，也没有初始化 Git 仓库。

## 1. 模型

水平导轨上的单自由度质量-弹簧-阻尼系统，$x$ 从弹簧自然长度处量起：

$$
m x'' + c x' + k x = u(t)
$$

- $m x''$：惯性，来自牛顿第二定律；
- $-k x$：弹簧恢复力，来自胡克定律；
- $-c x'$：黏性阻尼；
- $u$：执行器力，也是 PID 的输出。

参数：$m = 1\ \mathrm{kg}$，$c = 1\ \mathrm{N\cdot s/m}$，$k = 4\ \mathrm{N/m}$。开环自然频率 $\omega_n = 2\ \mathrm{rad/s}$，阻尼比 $\zeta = 0.25$，欠阻尼。开环静态增益 $1/k = 0.25\ \mathrm{m/N}$；要稳态保持在 $x = 1\ \mathrm{m}$，需要 $k x = 4\ \mathrm{N}$ 的保持力。

## 2. 状态变量与控制器

状态定义为：$x_1$ 位置、$x_2$ 速度、$x_3$ 误差积分（PID 的 I 项）。

$$
\begin{aligned}
x_1 &= x, \quad x_2 = x', \quad x_3 = \int (r - x_1)\,dt \\
x_1' &= x_2 \\
x_2' &= \frac{u - c x_2 - k x_1}{m} \\
x_3' &= r - x_1 \\
u &= K_p(r - x_1) + K_i x_3 - K_d x_2
\end{aligned}
$$

二阶对象拆成两个一阶状态；I 项本身是一个积分器，作为第三个状态一起积分。D 项作用在测量速度 $-K_d x_2$ 上，避免阶跃参考在 $t=0$ 产生微分冲激。

## 3. 闭环公式

把 $u$ 代入对象方程：

$$
m x'' + (c + K_d) x' + (k + K_p) x = K_p r + K_i x_3
$$

对时间求导（$t>0$ 时 $r$ 为常数）：

$$
m x''' + (c + K_d) x'' + (k + K_p) x' + K_i x = K_i r
$$

闭环特征方程：

$$
m s^3 + (c + K_d) s^2 + (k + K_p) s + K_i = 0
$$

### Ki = 0：二阶降阶模型

此时特征方程退化为 $s\left[m s^2 + (c + K_d) s + (k + K_p)\right] = 0$。$s=0$ 是未被使用的积分状态；稳定性与阻尼看二次部分。其中 $\omega_n$ 是自然频率，$\zeta$ 是阻尼比，$M_p$ 是相对稳态值的超调量：

$$
\begin{aligned}
w_n &= \sqrt{\frac{k + K_p}{m}} \\
\zeta &= \frac{c + K_d}{2\sqrt{m(k + K_p)}} \\
M_p &= \exp\left(-\frac{\pi \zeta}{\sqrt{1 - \zeta^2}}\right)
\end{aligned}
$$

对 $K_p=10$、$K_d=0/3$，$\omega_n=3.7417\ \mathrm{rad/s}$，$\zeta=0.1336/0.5345$。实测超调与公式逐位吻合（见验证记录）。

### Ki > 0：三阶系统

系统是三阶的，**不能**用一个 $\zeta$ 概括，也不能把二阶超调公式当作预测。应同时看：

- 三个闭环极点（特征根）；
- 闭环零点 $s = -K_i/K_p$（分子为 $K_p s + K_i$）；
- Routh 判据 $(c + K_d)(k + K_p) > m K_i$；
- 实际仿真结果。

零点与慢极点的相对位置会显著改变响应。例如 $K_d=3$、$K_p=10$ 时，$K_i=5$ 的零点 $-0.5$ 靠近慢极点 $-0.398$，近似极零相消，实测超调为 0%；而 $K_i=30$ 的复极点阻尼较低，实测超调 53%。

## 4. 指标定义（重要）

- $\mathrm{rise}(s)$：归一化响应 $y/y_{ss}$ 首次从 10% 到 90% 的时间；
- $\mathrm{overshoot\%}$：$100 \max(0, \max(y)/y_{ss} - 1)$；
- $\mathrm{settle2\%}(s)$：归一化响应最后一次离开 $y_{ss}$ 的 ±2% 带的时间；
- $\mathrm{ess}(m)$：$|r - y_{ss}|$，其中 $y_{ss}$ 是记录最后 10% 时间内的样本均值，始终只是末端稳态估计值。

**超调、上升、调节时间都是相对各自的稳态值 $y_{ss}$，不是相对参考值 $r$。** 对 P/PD，$y_{ss} = 0.7143$，不是 1；如果把超调算成相对 $r$，P 的 65% 超调会被压成 18%，PD 甚至会因为永远到不了 $0.9r$ 而出现 `NaN`。稳态误差单独放在 $\mathrm{ess}$ 列，和瞬态指标分开看。

### 4.1 指标有效性（2026-10-26）

`pid_metrics` 保留 `steady_value`、`steady_error` 两个数值字段；即使记录未收敛，它们仍表示尾段估计及其参考误差，不能脱离有效性字段当作已确认稳态。新增字段：

| 字段 | 类型与含义 |
|---|---|
| `steady_state_valid` | logical：记录在指定误差带精度下支持位置稳态估计 |
| `steady_state_reason` | char：通过或不能确认的原因码 |
| `settling_time_valid` | logical：是否可报告本记录内观察到的调节时间 |
| `settling_time_reason` | char：调节时间有效或无效的原因码 |
| `convergence` | struct：窗口起点、两段样本数、`deviation`、`drift`、`budget` |

设记录跨度为 $L=t_{end}-t_{start}$，估计窗口为最后 $0.1L$，检查窗口为最后 $0.2L$。检查窗口由两个相邻的原长度估计窗口组成，用较早一段帮助识别正在变平的暂态。判据为：

1. 检查窗口的前半段 `[80%,90%)` 和后半段 `[90%,100%]` 各至少 3 个实际样本，即各有至少两个可观察的采样间隔；不通过插值制造样本。
2. 令指定误差带半径 $\delta=\mathrm{band}|y_{ss}|$（默认 `band=0.02`）。`deviation` 是检查窗口内 $\max|y-y_{ss}|$。
3. 在检查窗口对 $y-y_{ss}$ 拟合含截距的直线，时间归一化为 $\tau=(t-t_{80\%})/(0.2L)$；`drift` 为拟合斜率的绝对值，即趋势在整个检查窗口跨度内对应的位置变化量。
4. 波动和趋势各分配一半误差带预算：两者都必须满足 `<= budget = δ/2`。这是保守的工程分配规则，不是从系统极点推得的误差界。无需固定秒数阈值，也不要求 $y_{ss}=r$。

原因码包括 `tail_within_budget`、`tail_variation`、`tail_trend`、`tail_variation_and_trend`、`insufficient_tail_samples`、`invalid_record`。未确认位置稳态时，上升时间、超调量、调节时间全部返回 `NaN`，因为它们依赖这个估计值归一化。零位置恒值可通过位置稳态检查，但相对零值的阶跃指标未定义，此时 `settling_time_valid=false`、原因是 `zero_steady_value`。有效调节时间的原因码为 `observed_settling`。

`saturation_metrics` 完整转发这些字段；它们只检查位置，不证明积分状态或整个闭环达到平衡。`simulate_disturbance` 的 `pre.metrics` 同样获得这些字段；扰动后的 `disturbance_metrics` 使用原有独立定义，本次未增加其恢复时间有效性判据。

**有限记录的限制：**有效标记是采样记录内、指定误差带精度下的判断，不证明渐近收敛或未来永不离带。小于预算的持续微小波动可能通过；采样之间的振荡、延迟发生的变化、非线性趋势也不能仅靠此判据排除。尾段均值仍按样本而非时间加权，以保留当前实验数值。有效性改进当时保留了采样交点算法；后续时间精度改进见 §4.2。

实测：PID-15 的 `T=1 s` 仍保留末端估计 `1.220094796 m`，但两个有效标记均为 `false`，原因 `tail_variation_and_trend`，三个瞬态指标均为 `NaN`。现有六组 `T=30 s` 的两个标记均有效；五个原数值字段与修改前逐项完全相同，§5、§11、§12 的基准表不改写。

### 4.2 时间指标插值精度（2026-10-26）

本节为后续计算方法更新。§5、§11、§12 的历史实验表保留，不能与本节插值结果混为同一次计算。控制律、模型、增益、`ode45`、容差、默认输出采样以及 §4.1 有效性判据均未改变。

**算法与接口**

- `pid_metrics(t,y,r,band,dydt)` 增加可选速度输入；空 `band` 仍表示默认 0.02。原 3/4 参数调用仍可用，采用分段线性插值。`simulate_pid` 和 `simulate_saturation` 传入已有状态 `x(:,2)`，采用分段三次 Hermite 插值；不额外积分或增加输出点。
- 仍相对于本组 `steady_value` 计算首次 10%→90% 上升时间、归一化超调和 ±2% 调节时间。每个三次段先求全部内部极值，分成单调小段，再对阈值穿越用 `fzero` 定位；调节时间取**最后一次从带外进入闭误差带**的时刻，边界相切不算离带。这可识别插值曲线在两个原采样点之间的离带与回带。
- 新增 `peak_time`（标量 double：记录内归一化插值响应第一次达到最大值的时刻）和 `time_method`（char：`linear` / `cubic_hermite`）。单调响应的峰值时间可能是记录终点，并不表示发生了超调。未通过原有效性判据时，`peak_time` 与其他瞬态指标均为 NaN。
- `response_time_metrics` 是内部计算辅助函数，只计算归一化插值曲线，不执行稳态认证。正式调用必须经 `pid_metrics` 的有效性检查。诊断中直接调用此辅助函数的交点不能当作有效稳态指标。
- `saturation_metrics` 的第十个可选参数转发速度。饱和时间仍以 `abs(u_des)>u_max+1e-9` 为准，但改为对**线性控制指令插值**累计超限时间、定位首次退出，并在同一时刻插值 `x3`、`u_des`。正负两侧分别计算，支持单个采样间隔内从正饱和穿越到负饱和。新增 `saturation_time_method='linear'`。力的切换处不强加光滑三次假设。
- `stage2_check` 两条轨迹都传入速度后比较，原断言容差不变。`simulate_disturbance` 的 `pre.metrics` 自动采用新方法；扰动后的独立 `recovery_time` 仍使用原采样定义，未在本任务中改动。

对于区间宽度 h、局部坐标 u=(t-t_i)/h，Hermite 多项式为

```text
p(u) = a*u^3 + b*u^2 + c*u + d
a = 2*y_i - 2*y_{i+1} + h*(v_i+v_{i+1})
b = -3*y_i + 3*y_{i+1} - h*(2*v_i+v_{i+1})
c = h*v_i,  d = y_i
```

它匹配两端位置和速度。光滑且端点精确时位置插值余项为四阶 O(h^4)；横向穿越的时间误差约为位置误差除以穿越速度。速度很小、边界相切、导数不光滑时，不能据此宣称统一的时间误差界。代码中的机器精度端点处理不是新物理阈值，也没有修改误差带。

**方法比较：固定原容差，PID-15，30 s**

**仍有限制：**插值曲线的完整极值搜索不能证明原 ODE 在采样间没有额外变化，更不证明记录后的行为。位置和速度自身带有积分误差；近切向交点对误差敏感，切换附近的光滑误差阶也可能下降。尾段均值和有效性仍受采样密度影响，Refine=1 即为反例。扰动后的恢复时间、控制峰值和误差积分仍使用原算法；本次没有把它们包装成同等精度的连续时间指标。

## 6. 结果说明什么

- **P**：P 相当于一根附加弹簧。稳态时 $(k+K_p)x_{ss} = K_p r$，所以 $x_{ss} = 10/14 = 0.7143$，$\mathrm{ess} = 28.6\%$。它上升最快（0.301 s），但超调 65.5%，调节 7.75 s，且永远停在 0.7143，不会到 1。物理上，稳态需要 4 N 的保持力，而 P 只能给出 $K_p e$，必须留一个非零误差才能凑出这 4 N。
- **PD**：D 相当于附加阻尼，$\zeta$ 从 0.134 提到 0.535，超调降到 13.7%，调节时间降到 1.55 s。但稳态时 $x'=0$，D 项消失，所以 $\mathrm{ess}$ 仍是 28.6%。D 只改瞬态，不改稳态。
- **PI**：I 项在稳态提供 $K_i x_3 = k r$ 的保持力，$\mathrm{ess}$ 降到 $1.7\times10^{-5}$。但没有 D，复极点的实部只有 -0.318，衰减很慢；实测超调 35.2%，调节 11.9 s。注意：实测 35.2% 远小于“只看复极点、套二阶公式”会猜到的 76%，因为零点 $-0.5$ 和慢极点 $-0.363$ 改变了响应形状。这正说明三阶系统不能用一个 $\zeta$ 预测。
- **PID-5**：零点 $-0.5$ 与慢极点 $-0.398$ 近似极零相消，超调实测为 0%，但上升变慢（0.648 s），调节 6.11 s。它“很稳”，但不快。
- **PID-15**：零点 $-1.5$ 与慢极点 $-1.457$ 也很接近；复极点阻尼适中。这是六组里综合最好的：上升 0.465 s，超调 24.2%，调节 2.63 s，稳态误差 1.3e-12。
- **PID-30**：上升最快（0.377 s），但复极点的实部只有 -0.593，衰减最慢；超调 53.3%，调节又回到 6.15 s。Ki 加得太多，稳态误差虽然更早被消掉，振荡却拖长了整体调节时间。
- **非单调性**：调节时间随 Ki 变化是 6.11 → 2.63 → 6.15 s，不是“Ki 越大越快”。在这组固定 $K_p=10, K_d=3$ 的参数里，$K_i=15$ 附近是折中最好的。

### 三阶系统的结构性权衡（韦达定理）

对 $K_i>0$，特征多项式是 $s^3 + 4s^2 + 14s + K_i = 0$（$m=1$，$c+K_d=4$，$k+K_p=14$）。由韦达定理，三个根之和恒为 $-4$：

$$
\begin{aligned}
K_i = 5 &: \quad -0.398 + 2(-1.801) = -4.000 \\
K_i = 15 &: \quad -1.457 + 2(-1.271) = -4.000 \\
K_i = 30 &: \quad -2.814 + 2(-0.593) = -4.000
\end{aligned}
$$

Ki 增大时，实根向左移动（积分模态变快），但复根对的实部必须向右移动（振荡衰减变慢）来保持总和不变。所以“消差更快”和“振荡更久”是同一个代数约束的两面。PID-15 让最慢模态的实部绝对值最大（约 1.27），因此调节时间最短；PID-5 和 PID-30 都各有一个更慢的模态（实根 0.398 或复根对 0.593）。

$\max|u|$ 几乎都等于 10 N，因为初始时刻 $u(0)=K_p r=10\ \mathrm{N}$，之后控制力下降到稳态保持力；它主要由初始比例踢动决定，不是这六组的主要区分量。

## 11. 第二阶段：常值外部扰动实验

> §10 的“边界”描述的是第一阶段；本节是独立新增的实验，不改变第一阶段的六组基线、参数和验证逻辑。§10 的下一步第 1 项（常值扰动）已在本节完成；第 2 项（执行器饱和/抗积分饱和）已在 §12 完成。

### 11.1 模型与实验设计

在对象输入端加入外部扰动力 $d(t)$：

$$
m x'' + c x' + k x = u + d(t)
$$

$$
d(t) = \begin{cases}
0, & 0 \le t < 10\ \text{s} \\
-4\ \text{N}, & t \ge 10\ \text{s}
\end{cases}
$$

$d_0 = -4\ \mathrm{N}$ 的方向与运动相反，大小等于参考位置处的保持力 $k r = 4\ \mathrm{N}$。这个符号是刻意选的：如果取 $d_0 = +4\ \mathrm{N}$，P 的稳态值会恰好回到 $x=1$，因为 $(K_p r + d_0)/(k + K_p) = (10+4)/14 = 1$，反而看不出扰动偏差；取负号才能让 P/PD 的稳态偏差清楚显现。

实验分两段积分：

1. $[0, 10]\ \mathrm{s}$：$d=0$，用原来的 `pid_rhs.m` / `simulate_pid.m`，所以这一段和第一阶段基线完全一致；
2. $[10, 30]\ \mathrm{s}$：$d=d_0$，用新增的 `pid_rhs_dist.m`，以上一段末状态为初值。

两段在 $t=10$ 拼接，避免把力阶跃抹平在一个求解步里。P、PD、PID-15 使用相同的 $m=1, c=1, k=4, r=1, x_0=[0;0;0]$、相同的扰动和相同的 $\mathrm{RelTol}=10^{-8}, \mathrm{AbsTol}=10^{-10}$。PID-15 取第一阶段综合最好的那组（$K_p=10, K_i=15, K_d=3$），不是新调参。第一阶段其余三组（PI、PID-5、PID-30）保留原结果，不参与本节对比。

### 11.2 指标定义（与阶跃调节时间区分）

- $\mathrm{pre\_err} = |r - y(10^-)|$：扰动前最后一个采样点的误差。P/PD 本来就有约 0.286 m 的稳态误差，这不是扰动造成的；PID 约为 0。
- $\mathrm{post\_ess} = |r - \mathrm{mean}(y(\mathrm{tail}))|$：扰动后最后 10% 时间（$t \ge 27\ \mathrm{s}$）的平均稳态误差。
- $\mathrm{max\_dev} = \max_{t\ge10} |y(t) - r|$：以参考值为基准的最大偏移，包含瞬态下冲，不只是最终稳态偏差。
- $\mathrm{max\_exc} = \max_{t\ge10} |y(t) - y(10^-)|$：以扰动前位置为基准的最大偏移，只反映扰动本身造成的偏移，排除了 P/PD 原本的约 0.286 m 稳态误差。
- $\mathrm{recovery}$：从 $t=10$ 起，误差最后一次离开 $|e| \le 0.02\ \mathrm{m}$ 带的时间；若到最后仍不在带内，记为 `never`（`NaN`）。**这是从扰动时刻量的恢复时间，不是第一阶段的阶跃调节时间。** 第一阶段的 $\mathrm{settle2\%}$ 是从 $t=0$ 起、相对各自稳态值 $y_{ss}$ 定义的；两者不能直接比较。
- $u_{\mathrm{pre}} = u(10^-)$，$u_{\mathrm{post}} = \mathrm{mean}(u(\mathrm{tail}))$，$\mathrm{delta\_u} = u_{\mathrm{post}} - u_{\mathrm{pre}}$，$\max|u| = \max_{t\ge10}|u(t)|$。

### 11.4 数学解释

**P/PD 为什么留下稳态偏差。** 令 $x'=x''=0$，扰动为常值 $d_0$。对 P/PD（$K_i=0$），稳态时 D 项也为 0，所以两者满足同一个力平衡：

$$
\begin{aligned}
k x_{ss} &= K_p(r - x_{ss}) + d_0 \\
\Rightarrow (k + K_p) x_{ss} &= K_p r + d_0 \\
\Rightarrow e_{ss} = r - x_{ss} &= \frac{k r - d_0}{k + K_p}
\end{aligned}
$$

代入 $k=4, r=1, d_0=-4, K_p=10$：

$$
\begin{aligned}
e_{ss} &= \frac{4 - (-4)}{4 + 10} = \frac{8}{14} = 0.5714\ \text{m} \\
x_{ss} &= 1 - 0.5714 = 0.4286\ \text{m}
\end{aligned}
$$

P/PD 没有“记忆”，只能靠当前的误差产生控制力。扰动要求额外的保持力，而 P/PD 只能通过改变 $x$ 来改变 $u = K_p(r-x)$；误差降到 0 时控制力也回到 0，无法抵消 $d_0$。所以稳态必须保留一个非零误差，这就是 P/PD 的固有偏差。PD 的 D 项只在暂态起作用，稳态 $x'=0$ 时消失，因此 PD 和 P 的稳态偏差相同。

**PID 的积分项在什么条件下消除偏差。** 对 PID，稳态时若 $e=0$，积分状态 $x_3$ 可以停在非零常值，提供额外控制力：

$$
u_{ss} = k r - d_0 = 4 - (-4) = 8\ \text{N}
$$

也就是说，积分项把 P/PD 缺少的 4 N 补上了；位置回到 $r=1$，弹簧力仍是 4 N，$u_{ss} + d_0 = 8 - 4 = 4\ \mathrm{N}$ 与弹簧力平衡。实测 $u_{\mathrm{pre}}=4.000\ \mathrm{N}$、$u_{\mathrm{post}}=8.000\ \mathrm{N}$、$\mathrm{post\_ess}=7.08\times10^{-12}\ \mathrm{m}$，和这个力平衡一致。

但“积分能消差”不是无条件的。闭环特征方程是

$$
m s^3 + (c + K_d) s^2 + (k + K_p) s + K_i = 0
$$

三个根都必须有负实部，系统才稳定，积分状态才会收敛到常值；Routh 判据给出

$$
(c + K_d)(k + K_p) > m K_i
$$

PID-15 的左边是 $(1+3)\cdot14 = 56$，右边是 $15$，余量 41 > 0，特征根为 $-1.2715 \pm 2.9459i$ 和 $-1.4570$，都在左半平面。若 $K_i$ 太大、Routh 余量变负，闭环不稳定，积分项不但不能消差，反而可能发散或持续振荡；所以“有 I 项”不等于“一定无静差”，还要看闭环稳定性。

也可以用终值定理看：对象 $G(s)=1/(m s^2 + c s + k)$，扰动到误差的传递函数是 $-G(s)/(1+C(s)G(s))$。P/PD 的 $C(0)=K_p$ 有限，扰动引起的误差部分是 $|d_0|/(k + K_p)$，加上参考跟踪误差后就是上面的 $(k r - d_0)/(k + K_p)$；PID 的 $C(s)$ 在 $s=0$ 有 $K_i/s$ 极点，$C(0)G(0) \to \infty$，所以常值扰动下 $e_{ss} \to 0$。这个结论同样以闭环稳定为前提。

**最大偏移与恢复。** 先区分两个基准：

- 以参考 $r=1$ 为基准，$\mathrm{max\_dev}$ 是 P 0.7562、PD 0.6106、PID-15 0.2686；P/PD 的数值包含了它们原本约 0.286 m 的稳态误差。
- 以扰动前位置 $y(10^-)$ 为基准，$\mathrm{max\_exc}$ 是 P 0.4669、PD 0.3249、PID-15 0.2686；这才是扰动本身造成的最大偏移。

P 的 $\mathrm{max\_exc}$ 最大，因为 P 阻尼低（$\zeta=0.1336$），扰动后先下冲到约 $x=0.244$ 再回到 $0.4286$；PD 的 D 项把 $\mathrm{max\_exc}$ 压到 0.3249；PID-15 的 0.2686 最小，并在 $1.7035\ \mathrm{s}$ 后回到 ±2% 带。$\max|u|$ 也反映了这个过程：P 为 7.562 N，PD 为 6.561 N，PID-15 为 8.394 N（积分项在恢复过程中略有过冲）。

**恢复时间 vs 阶跃调节时间。** 第一阶段的 $\mathrm{settle2\%}$ 是 P 7.7468 s、PD 1.5523 s、PID-15 2.6321 s，从 $t=0$ 量、相对各自 $y_{ss}$；本节的 $\mathrm{recovery}$ 从 $t=10$ 量、相对 $r=1$。P/PD 的 $\mathrm{recovery}$ 是 `never`，因为它们的扰动后稳态误差 0.5714 m 远大于 0.02 m 带；这不是“恢复得慢”，而是“稳态根本不在带内”。PID-15 的 1.7035 s 与第一阶段的 2.6321 s 数值接近，但测量的是不同事件，不能当成同一个指标比较。

### 11.5 验证记录

1. 扰动前轨迹 vs 独立基线：P $4.540\times10^{-8}$，PD $2.827\times10^{-11}$，PID-15 $9.713\times10^{-9}$，均 $< 10^{-6}$。

## 12. 第三阶段：执行器饱和与积分饱和（windup）

> 本节是独立新增的实验，不改变第一、二阶段的基线、参数和验证逻辑。

### 12.1 模型与控制器

对象仍为：

$$
m x'' + c x' + k x = u_{\mathrm{act}} + d(t)
$$

第三阶段取 $d(t)=0$，隔离饱和效应。控制器为 PID-15，执行器加入对称限幅：

$$
\begin{aligned}
e &= r - x_1 \\
u_{\mathrm{des}} &= K_p e + K_i x_3 - K_d x_2 \\
u_{\mathrm{act}} &= \min\left(u_{\max}, \max\left(-u_{\max}, u_{\mathrm{des}}\right)\right)
\end{aligned}
$$

其中 $u_{\mathrm{des}}$ 是控制器期望的控制力，$u_{\mathrm{act}}$ 是执行器实际施加的控制力。

状态方程：

$$
\begin{aligned}
x_1' &= x_2 \\
x_2' &= \frac{u_{\mathrm{act}} - c x_2 - k x_1}{m}
\end{aligned}
$$

积分状态导数 $x_3'$ 由下面的三种积分律决定。

三种积分律：

- G1 理想执行器：$u_{\mathrm{act}} = u_{\mathrm{des}}$，$x_3' = e$。
- G2 饱和无抗饱和：$u_{\mathrm{act}} = \mathrm{sat}(u_{\mathrm{des}})$，$x_3' = e$。执行器到顶后积分器仍继续累积。
- G3 饱和 + clamping：$u_{\mathrm{act}} = \mathrm{sat}(u_{\mathrm{des}})$；当 $(u_{\mathrm{des}} - u_{\mathrm{act}}) e > 0$ 时 $x_3' = 0$，否则 $x_3' = e$。即饱和且误差继续把控制量往同一方向推时冻结积分。

注意：$x_3$ 在 G3 中不再严格等于 $\int e\,dt$，而是带条件冻结的控制器积分状态。

### 12.2 执行器上限的选择

$u_{\max} = 5\ \mathrm{N}$，依据是可直接算出的量：

- 稳态保持力 $k r = 4\ \mathrm{N}$。$u_{\max}=5\ \mathrm{N}$ 是它的 1.25 倍，留 25% 余量，保证 $x=1$ 物理可达。
- 未饱和初始指令 $u_{\mathrm{des}}(0) = K_p r = 10\ \mathrm{N}$。$u_{\max}=5\ \mathrm{N}$ 是它的 50%，因此 $t=0$ 必然饱和。
- 饱和状态下的开环平衡位置 $u_{\max}/k = 1.25\ \mathrm{m}$，高于 $r=1$，系统有恢复能力。

$u_{\mathrm{des}}(0)$ 与 $\max|u_{\mathrm{des}}|$ 分开记录：前者是初始指令，后者是整个仿真区间的期望力峰值。本实验中两者都等于 10 N，但这不是未经验证的假定，验证脚本分别检查。

### 12.3 三组设置

| 组 | `u_max` | 积分律 | 作用 |
|---|---:|---|---|
| G1 | `Inf` | `x3'=e` | 理想执行器基准 |
| G2 | 5 N | `x3'=e` | 展示 windup |
| G3 | 5 N | 条件冻结 | 展示 clamping 的改善 |

三组共享 $m=1, c=1, k=4, r=1, x_0=[0;0;0], T=30\ \mathrm{s}$、PID-15（$K_p=10, K_i=15, K_d=3$）和 $\mathrm{RelTol}=10^{-8}, \mathrm{AbsTol}=10^{-10}$。

### 12.5 结果说明

- **G2 的 windup**：饱和持续 0.5950 s，首次退饱和时积分状态已达 0.4527；积分峰值 0.4874，高于 G1 的 0.3863。超调从 G1 的 24.19% 升到 33.25%，调节时间从 2.63 s 升到 3.48 s，IAE 从 0.5980 升到 0.7779。这是“执行器到顶后积分继续累积”的直接后果。
- **G3 的 clamping**：饱和期间冻结积分，首次退饱和提前到 0.2696 s，且此时 $x_3=0$；积分峰值 0.2681，低于 G2 的 0.4874，也低于 G1 的 0.3863（因为 G1 在同样早的时间段内没有被限幅，积分正常累积）。超调降到 8.26%，调节 2.7550 s，IAE 0.6087，均明显优于 G2。
- **一个需要如实记录的 trade-off**：G3 的超调低于 G1（8.26% vs 24.19%），但上升更慢（0.6268 s vs 0.4649 s），调节时间和 IAE 略高于 G1（2.7550 vs 2.6321 s；0.6087 vs 0.5980）。clamping 的收益是抑制 windup，不是把饱和系统“恢复成”理想系统；它用较慢的初始上升换取更小的超调。
- **饱和本身不必然造成稳态误差**：因为 $u_{\max}=5\ \mathrm{N} > k r = 4\ \mathrm{N}$，三组最终都回到 $x=1$。若 $u_{\max} < k r$，参考位置物理不可达，抗饱和只能防止积分器无限增长，不能消除稳态误差；本轮未做该反例。
- **局部极点只描述未饱和区**：三组的未饱和闭环极点都是 $-1.2715 \pm 2.9459i, -1.4570$，Routh 余量 41；这些量不能用来预测饱和段的超调。

### 12.6 验证记录

`verify_saturation` 全部通过：

1. **数学规则**：饱和、限幅、clamping 冻结/放行、默认 $u_{\max}=\infty$、非法 $u_{\max}$/$\mathrm{aw\_mode}$ 报错、`pid_rhs_sat` 与 `pid_control_sat` 一致。
2. **G1 基准等价**：与第一阶段 `simulate_pid` 的 PID-15 轨迹逐位一致，$\max|y - y_{\mathrm{base}}| = 0$，$\max|u_{\mathrm{act}} - u_{\mathrm{base}}| = 0$，四项指标差为 0。
3. **G2/G3 限幅**：全程 $|u_{\mathrm{act}}| \le 5 + 10^{-9}$；$\max|u_{\mathrm{des}}| = 10\ \mathrm{N}$，$\max|u_{\mathrm{act}}| = 5\ \mathrm{N}$；饱和确实发生。
4. **clamping 不变量**：G3 轨迹上所有“饱和且误差同向”的采样点（119 个）均满足 $x_3' = 0$，$\max|x_3'| = 0$。
5. **项目特定现象**：G2 首次退饱和时 $x_3=0.452683$，G3 为 $0.000000$。$x_3(\mathrm{first\ desat}) \approx 0$ 只在本项目初值和参数下成立，不是 clamping 的一般数学不变量；验证脚本按项目级现象加容差断言。
6. **稳态**：三组 $y_{ss}=1.0000000000$，$x_{3,ss}=0.2666666667$（与 $k r/K_i$ 一致），力平衡残差 $< 10^{-10}\ \mathrm{N}$。

8. **性能排序**：G2 超调/调节/IAE 明显大于 G1；G3 明显小于 G2。断言阈值由本次试跑数据设定：超调余量 5 个百分点、调节时间余量 0.3 s、IAE 余量 0.05；G3 超调低于 G1 的观察也按 5 个百分点余量锁定。
